# E-commerce Analytics

Анализ данных бразильского e-commerce маркетплейса с использованием SQL и Python.

## Инструменты
SQL • SQLite • Python • pandas • matplotlib

## Что анализируется
- динамика стоимости доставленных заказов
- товарные категории
- география клиентов
- способы оплаты
- связь между количеством платежей в рассрочку и средней стоимостью заказа

## Ключевые выводы
- стоимость доставленных заказов заметно выросла в рассматриваемом периоде
- São Paulo лидирует по совокупной стоимости доставленных заказов
- health & beauty — ведущая категория по денежному объёму
- более длительная рассрочка в целом связана с более высокой средней стоимостью заказа

## Файлы проекта
- `ecommerce_analysis.ipynb` — полный Python-анализ
- `ecommerce_analysis.sql` — SQL-запросы и агрегации
- PNG-файлы — визуализации проекта
